# Rowllah T Basheer: Portfolio

Personal portfolio website. Plain HTML, CSS and JavaScript, hosted on GitHub Pages.

## Customising

- **Profile photo:** add a square image at `assets/profile.jpg`. Until then, the site shows the initials "RB".
- **Content:** edit `index.html`.
- **Colours:** change the CSS variables at the top of `styles.css`.

## Preview locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
